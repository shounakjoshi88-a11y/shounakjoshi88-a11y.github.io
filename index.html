how everything here gets built

01plan

Break the task into parts small enough to check. Flux runs twenty-one tools this way; this page runs one canvas loop this way.

02execute

Stream results the moment they exist, interleaved with prose. A verifier can only trust what it has watched arrive.

03verify

Judge the result, not the intent. Noise is refused. A stale counter is wrong. One bad extraction poisons everything after it.

04retry

Loop with the failure attached. Every bug I hit becomes a named regression test rather than a quiet fix.

Flux

Bun · Express 5 · React 19 · pgvector · NVIDIA NIM · Electron

Twenty-one tools behind one loop: plan, execute, verify, retry. The tools were the easy part. Because streaming interleaves tool results with prose, the verifier has to judge results it has not finished receiving, and vector memory re-injects itself into later calls — so one bad extraction quietly poisons every answer after it.

StudyDesk

React · Vite · Capacitor · on-device OCR · Android

The Android app I use every day, which is a harder review than a stranger gives it. A photographed timetable becomes real classes through on-device OCR, so the grid parser has to survive dark backgrounds, all four rotations, and 12 px labels that binarise into blobs. It is also built to refuse: noise cannot become a 19:20 lecture.

Stellar Forge

React · Three.js · Bun · Prisma

Looks like a CRUD app with a 3D header, and the 3D header is the easy part. Seat claims have to be race-safe across concurrent users, so registration runs in serialisable transactions with row locking, and the live counter is one source of truth rather than whatever each client last fetched.

Read the repo

de-ai

Python · rule-based rewrite engine · FastAPI

A rewriter that calls no model, so the same input gives the same output every time. The cost of that determinism is that a rule bank will happily turn server into waiter, so the lexical pass is fenced off from a 600-term technical blocklist, and the pipeline re-scans its own output and reverts any swap that introduced a new tell.

Meridian

Python · Flask · CSV · real ICD-10-CM data

Clinical triage built only from six lab practicals on real ICD-10-CM data. No ORM because none was taught, no framework for the same reason. The part I would not have guessed is that every generator bug ended up as a named regression test rather than a quiet fix.
